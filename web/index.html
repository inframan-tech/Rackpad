Secure connection

Lets Rackpad use the microphone and the live camera. Once per phone, about a minute. Everything stays on your Wi-Fi.

  1. Download Rackpad's certificateSafari asks to allow a configuration profile: tap Allow.
    Download
  2. Install itSettings → General → VPN & Device Management → Rackpad Local CA → Install
  3. Trust itSettings → General → About → Certificate Trust Settings → switch on Rackpad Local CA
  4. Install itSettings → Security → More security settings → Encryption & credentials → Install a certificate → CA certificate → pick Rackpad.crt

Then add the secure Rackpad to your Home Screen, and delete the old icon.

Make it full screen

Tap Share, then Add to Home Screen. Rackpad then opens from its own icon with no browser bars, and finds your Mac by itself.
